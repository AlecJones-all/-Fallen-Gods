# 七、主要角色档案（性格·秘密·动机·弧线）

## 炉婆（余烬炉守炉人）
- **性格**：暖、絮叨、装糊涂。用食物说话，问句以外只用问句回答。全场唯一不说教的人。
- **秘密**：帷母「想醒来的那部分mind」化成的人形；上一场梦里她是林野的母亲。记得一切轮回。
- **动机**：她不想醒，也不想睡——她想「有人陪着做梦」。一万年来她收留每一个不焚者，是在给梦找伴。
- **弧线**：糊涂老妇 → 被玩家识破后的坦然 → 真结局里第一个「共梦者」。无黑化线；她的恐怖在于温柔本身是宇宙级的。
- **语癖**：「饿不饿？」「疼的地方，我帮你揉揉。」揭底后重读，每句都是伏笔。

## 阿舍尔（烬裔，身份一）
- **性格**：闷、烈、认死理。愤怒时烬纹发烫，他习惯把手按在雪里降温。
- **秘密**：他的名字不是被火烧掉的——是养叔亲手从忆簿上划掉的，划之前犹豫了一夜（簿页有泪痕）。
- **动机**：复仇 → 救莉薇娅 → 最终是「不再替任何人单方面做决定」。
- **弧线**：恨的燃料 → 发现恨错了对象 → 发现爱人也骗过他 → 学会把选择权还给别人。内在需求（放下）与外在目标（杀/救）全程拉扯。

## 林野（人类穿越者，身份二）
- **性格**：务实、嘴碎、用做饭和吐槽对抗恐惧。神话当前，他先找醋。
- **秘密**：他的记忆里没有镜子。他是上一场梦的遗民，不是天选之人。
- **动机**：回家吃饭。全程不升华——这是他最锋利的地方：世界要灭亡了，他惦记的还是那顿没吃完的年夜饭。
- **弧线**：异乡人 → 发现家就在隔壁（炉婆）→ 发现回去等于遗忘 → 选择让两场梦同桌。他的感情线是亲情，不硬配爱情。

## 雀（换生灵，身份三）
- **性格**：怯而韧，擅长察言观色（线视养出来的生存技能），被保护时会先道歉。
- **秘密**：名字烧过两次；上一轮的他跪着求龙签契。他忘了自己救过她。
- **动机**：配得上她 → 查清自己是什么 → 「这次先问她愿不愿意」。
- **弧线**：易碎品 → 发现温柔里有合同 → 发现合同是自己签的 → 以脆弱持有强者之命。弱者的成长不是变强，是敢于承担别人的命。

## 莉薇娅（灯芯圣徒，誓缚者）
- **性格**：锋利、爱开玩笑，用玩笑包裹恐惧。左撇子，绣活极好。
- **秘密**：签卖身契时就知道村子保不住；她记得每一轮；纱幔上绣的是村图和他的小名。
- **动机**：最初是救村（失败），现在是「别让他替我上灯座」。
- **弧线/黑化**：默认线从「别救我」到「换我救你」（E1后成为炉边誓缚者，为玩家而战）；黑化线「熄灯者」——玩家反复用她的寿命换碎片（绣品支线拾取过多），她烧穿纱幔成Boss，台词只剩一句：「这次，换我忘了你。」

## 维斯佩拉（最后的金龙，誓缚者）
- **性格**：话极少，从不叫雀的名字。温柔与控制欲同源：她记得一切，他忘了一切，她只能把他看得死紧。
- **秘密**：名契是雀求的；她七年的「换鳞期」是替他流血；她怕炉火，因为契约会显形。
- **动机**：让他活着——既是爱，也是自救，两者她自己也分不清，这是她最深的羞耻。
- **弧线**：守护者 → 被揭穿的「自私者」→ 把条款摊开给他看 → 断名（陌生）或系心（平等）。她学会的事：爱不是把人护在翼下，是把账本递过去。

## 克莱门斯（灰烬主教，誓缚者，大BossⅠ）
- **性格**：疲惫的公务员，用布道腔说最残忍的话。第一个不焚者，轮回了三百次。
- **秘密**：每次屠村都漏杀孩子；他跪的方向是笼子；他以为交易是真的，被塞维林骗了三百年。
- **动机**：维持献祭——「我杀一村，救一世界，这账我认。」
- **弧线**：狱卒 → 被玩家戳破信仰 → 救赎线（献出自己的名字为玩家开节点14的门）或沉沦线（得知被骗后投向唤醒派，成为节点12精英敌）。

## 塞维林（大祭司，唤醒派领袖，主反派）
- **性格**：温和、博学、给养子写过最温柔的家书。说话像播种的人。
- **秘密**：焚村令签发者；阿舍尔的养叔；他把自己炼成了唤醒之钥。
- **动机**：「在谎言里活着不算活着。」他爱这个世界，所以要给它一个真实的黎明——哪怕黎明烧掉所有人。他不是疯子，是彻底的诚实主义者。
- **弧线**：慈父幻影 → 纵火者 → 摊牌者 → 终Boss（唤醒路线）。他不黑化——他从第一页就是黑的，只是玩家先看见了他的白。

## 赫恩（白牡鹿王，大BossⅡ）
- **性格**：荣誉、克制、劝退多于羞辱。神里最像骑士的一个。
- **秘密**：他知道唤醒派是对的，也知道沉睡派是必要的；他选择尽职，因为「总得有人站岗」。
- **动机**：守住锚点。对三身份态度迥异：烬裔是「孩子」，人类是「客人」，换生灵是「悬赏」。
- **弧线**：狱卒 → 可被说服的让路者 → 守夜路线终Boss战中第一个退场的神（若玩家此前停手）→ 真结局里自愿成为第一个轮值梦者。

## 欧玻洛斯（币冕）
- **性格**：市侩、幽默、唯一会跟凡人开玩笑的神。找零永远多给一枚旧币。
- **秘密**：空席唯一的债主与守墓人；旧世界的气泡是他每天用利息续着的。
- **动机**：还一笔一万年的债——空席拆神格前托他「照看没做完的梦」。
- **弧线**：奸商 → 守墓人 → 真结局里债务清零，他第一次不收钱。

## 蓟相（仙灵法庭宰相，小Boss）
- **性格**：说话像合同条款，笑像在盖章。喜剧化的可怕。
- **秘密**：他自己也是换生灵——当年被抱走的那个真婴的替代品，爬到了宰相位。他针对雀，是恨「同类里居然有人被爱」。
- **动机**：让一切关系回到账面上。爱是他唯一不会记的账。
- **弧线**：讨债人 → 被免债时的系统错误式崩溃 → 可成为法庭阵营盟友（他第一次做了一笔没有利息的交易）。

## 空心的萨姆（剥制师，小Boss）
- **性格**：礼貌、空洞、对临终之言有职业性的温柔。
- **秘密**：不焚者，名字烧了三百年；账簿里一句真话都没上交过。
- **动机**：收集「没人听过的最后一句话」——他在替世界记住没人记得的人。
- **弧线**：工具人 → 账簿支线后的炉边NPC → 真结局共梦者名单的朗读者。
