# 美术资产总索引

本目录收录角色造型、设定板、已选场景模型和后续修改参考件，供美术制作和后续接入 Godot 使用。场景模型见[场景资产索引](environments/README.md)。模型底件与造型参考位于 `art/references/`，因属第三方 IP 仅限本地研究与修改，不随仓库分发。
每个角色一个文件夹，模型与设定板同名共存，不改原文件名，方便与设计过程记录对照。

## 目录约定

```
art/
├── README.md            # 本文件
├── environments/        # 已选场景模型、造型预览、税卡试摆与署名
├── references/          # 供后续修改、重制和动作试验的模型基础（第三方 IP，仅本地，不入库）
└── characters/
    └── <角色>/
        ├── <角色>.glb                  # 主模型
        ├── <角色>-<变体>.glb           # 配件 / 未贴图 / 高模等变体
        ├── <角色>角色设定板.png         # 总览设定板
        ├── <角色>角色设定板-<工序>.png  # 迭代稿，保留过程
        └── README.md                  # 该角色的状态、数据与待办
```

## 提交前注意

1. 仓库根目录已加入 `.gitignore` 规则，`*.glb` / `*.png` 只允许出现在 `art/` 下，避免再次散落。
2. 角色与场景目录中的 GLB 和 PNG 使用 Git LFS。
3. 单文件均小于 100 MB（最大为 `苏醒之心/苏醒之心.glb` 75.1 MB），未触及 GitHub 硬限；超过 50 MB 会有提示但不阻断。
4. 每个角色的「来源与授权」仍为待补状态，公开仓库前必须填写，尤其是七神系列与同人参考来源。
5. 根目录的 `tmp_lead.png`、`tmp_lead_dim.png`、`tmp_walk.png` 是引擎内截图，未收录；确认后可自行清理。
6. 尚未执行 `git add` / `commit`，工作区只做了移动与新增。
7. `art/references/` 为第三方 IP 参考件（Warcraft 同人重制、Hircine 等），按原作者许可仅限本地造型研究，已加入 `.gitignore`，公开仓库不包含该目录。
