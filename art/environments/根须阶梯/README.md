## 审查结论

**符合提示词的部分**

- 根须造型合格：粗大、有分叉与细末梢，缠在拱券和柱身上，末端铺到地面，读起来是"从墙里长出的"而不是贴片。
- 血肉墙的主体关系对：墙体是干净的旧石灰砌块，血肉只出现在裂缝与破损处，没有触手群和眼球，克制方向正确。
- 拱门台阶这一件把"阶梯"和"根须"放进同一个模组，正好对上第6关的关卡名。

**判定（2026-11-29）：三件可直接使用**，不阻塞关卡，也不等减面。下面这些只是备注，按需再处理。

**备注（按优先级）**

1. **面数偏高。** 每件 175–200 万面、70 MB 左右。摆放没问题，但同屏多件会明显吃帧；需要优化时按第4关那批的做法减到 1–3 万面、贴图降到 1024–2048，另存 `-游戏` 后缀。
2. **尺寸需在摆放时放大。** 三件都只有 0.65–0.75 m 高，GLB 节点上没有缩放（第4关那批有节点缩放，所以是米制）。当 3 m 拱门用就整体放大约 4 倍。
3. **血肉墙宜当转角/尽端件。** 它自带楼梯和基座，形制接近"墙角转角件"；要铺成连续墙面，需拆出纯墙面部分或只用它收角。
4. **血色可按需压暗。** 裂缝里的红偏朱红，缺少暗部与湿润感，可在 Godot 材质里压暗 albedo、加一点次表面暖色，只保留裂缝处高光。
5. **脉动光在 Godot 侧做。** 材质无自发光，根须"柔和脉动光"与血肉"仍然活着"用灯或 shader 脉动实现，与第4关祭龛的做法一致。
6. **无碰撞体、无 LOD、UV 不复用。** 碰撞按关卡脚本给盒体；UV 是一次性整块展开，不能靠平铺省贴图。

**建议用法**

- 直接当第6关的入口拱、转角墙与楼梯装饰使用，放大到 3 m 级即可。
- 同屏实例控制在少数几件；需要批量铺设时，再走减面流程另存 `-游戏` 件。
