# 15 · 一周版玩法与数值定稿（对齐 BALL x PIT · v2.0）

> 本文件是**面向一周开发的可执行定稿**，玩法**对齐 BALL x PIT（球比伦战记）**：横屏打砖块 + 手动瞄准 + 击杀经验升级 + 弹珠槽/饰品槽 + 基地建设。
> **依据**：00–04 剧情冻结事实 + 08 数值锚点 + BALL x PIT 机制参照 + 06 术语表。剧情事实以 00–04 为准，视觉以 17 号为准。
> **v2.0 变更**（2026-11-23）：玩法从"竖屏自动割草"整体切换为"横屏打砖块（对齐 BALL x PIT）"；属性/数值/经济/七境沿用此前已锁值。
> **决策**：Godot+H5；完整 15 关；**横屏**；视觉见 17（形似占位，非纯色块）；手动瞄准；击杀经验升级；弹珠/饰品槽；基地建设；希腊皮 + 深坑骨。

## 一、核心玩法（对齐 BALL x PIT）

### 1.1 核心循环

```
横屏战场：玩家在底部 → 手动瞄准发射弹球 → 弹球在"方块砖块墙"间反弹造伤
      ↑                                                    ↓
  走位躲敌弹 / 调反弹角度 ← 弹球反弹           杀怪得经验 → 升级 → 三选一（弹珠/饰品/属性）
清光砖块墙 → 进度推进 → 下一波 / Boss 节点 → Boss 战
```

### 1.2 发射（手动瞄准）

- 触屏：按住拖动拉出瞄准线，松手发射。
- PC：鼠标指向 + 点击发射。
- 弹球朝瞄准方向飞出，撞砖块/墙/玩家反弹；反弹次数耗尽或落回底部消失。

### 1.3 成长（击杀经验升级）

- 持续刷砖块墙，杀怪掉经验；经验满 → 升级 → **三选一**：新弹珠 / 新饰品 / 属性点。
- 升级短暂停（≤1s），不打断战斗节奏。
- **去掉"波次"概念**：以"刷怪进度条"推进；Boss 在关卡固定进度节点出现，不受三选一影响。

### 1.4 装备（弹珠槽 + 饰品槽 + 进化）

- **弹珠槽 4 + 饰品槽 4**。
- 弹珠 = 攻击（8 种，见二）；饰品 = 被动（10 种，见三）。
- 弹珠/饰品各 3 级；满级后两两**进化超武**（次做，见十、取舍）。

## 六、污秽（深坑污染）

- 0–100，局内仪表。
- **涨**：混沌弹珠使用、每关自然 +5；被敌弹命中 +1、被精英 / Boss 命中 +2。
- **降**：净礼坛（每关 1 个，花 20 Ichor 净礼 −15）、护盾球碰球 −1（每秒 1 次）。
- **影响**：混沌弹珠伤害加成 = 污秽值 × 0.5%（0~+50%）；跨档触发恐怖氛围文字。
- 恐怖文字分级：0–30 清明 / 30–60 低语 / 60–90 裂隙 / 90–100 溶解，跨档在战斗飘字出 1 句（不接完整疯狂事件）。
- **不决定结局**（单线 E1）。

## 七、怪物（砖块墙 / 精英 / Boss）

> 视觉（造型/尺寸/配色/动画）以 **17 号视觉规范**为准；本节只定形态类别与玩法。

- **小怪 = 带脸方块砖块**：排成砖块墙，从上方逼近；弹球在砖块间反弹清除。
- **精英 = 大型特殊方块**（2×1 或 2×2，带装饰/红光）。
- **Boss = 大型原创生物**（巨蛇/冰晶巨物等），专属弹幕 + 名称血条。
- 数值与倍率见十、2.3；Boss 机制见 16 号第三节。

## 八、存档与重试边界

**运行结构：每关 = 独立小局**：
- 局内（每关重置）：升级构筑（弹珠/饰品）、污秽值、当局 Ichor。
- 局外永久：七境、证据碎片、蚀痕、弹珠卡组 + 等级、已解锁关号、已读剧情、基地。

**存档点**：每关通关结算后自动存档。关卡内不设中途存档。

**死亡重试**：死亡 → 「重试当前关」（叙事 = 保命圣印烧母亲神性，见 08 第十一节）→ 整关重开，构筑 / 污秽 / 当局 Ichor 全部重置，不回第 1 关。

**Ichor 与武器成长**：弹珠卡组 + 等级跨关永久保留；当局未花完的 Ichor 清零（花掉变永久、存着清零）。

**主菜单 / 开始流程**：打开显示「继续」（进入已解锁关，首启第 1 关）；死亡显示「重试当前关」。无选关界面（极简）。音频 SE/BGM 后置，先做无声可玩版。

## 九、展示（横屏）

- **横屏宽幅**：战斗 = 横屏打砖块战场（底部玩家 + 上方砖块墙/Boss + 纵深场景）；剧情 = 横屏对话覆盖层（隐藏战场，露背景 + 人物 + 底部对话框）。
- UI 布局：左侧弹珠槽 + 饰品槽（图标 + 等级）；顶部货币；右侧 Boss 血条 / 进度；右上加速 / 跳过。
- 字数：剧情对话 ≤40 字/屏；战斗飘字 ≤20 字。

### 10.3 精英 / Boss 倍率与弹幕

- **精英**：HP = 小怪 × 3；碰撞伤 = 小怪伤 × 1.5。
- **Boss**：HP = 小怪 × 15；碰撞伤 = 小怪伤 × 2。适用有血条的 Boss（刻菲索斯 / 阿奈提俄斯 / 宙斯）。
- **弹幕伤害**：精英 / Boss 弹幕单发 = 其碰撞伤害 × 0.5（精英弹 = 小怪伤 ×0.75，Boss 弹 = 小怪伤 ×1.0）。
- **特殊**：心魔（第 10 关）= 生存战、卡俄斯（第 15 关）= 隔绝进度，均无血条。

### 10.4 经济闭环（Ichor + 律法残片）

**Ichor 获取**：普通怪 2 / 精英 15 / Boss 40 / 每关结算 20（首通 +50）。

**净礼坛**（每关 Boss 前 1 个；第 1 关在最后一段墙前）：净礼 20 Ichor（污秽 −15）/ 疗愈 15 Ichor（回血 +50）/ 强化 20 Ichor（指定三属性 +1 项）。

**结算商店**：新弹珠 50 Ichor / 升级 凡→灵 60 / 灵→神 150 / 买属性点 30。

**律法残片**：精英 1 / Boss 2；当前**秩序**弹珠升到神档后，3 残片 → 1 神器（结算自动合成，伤害基准 50）。混沌弹珠不可升神器。

### 10.5 反弹 / 软上限 / 操作 / 弹球物理

- 反弹次数：初始 3，buff 可叠至 8。弹球数：初始 1，叠至 6。
- 软上限：神力 100、攻速 ×3、弹球 6、反弹 8。
- 输入：触屏拖动瞄准、松手发射；PC 鼠标瞄准、点击发射；移速 300 px/s（神速每 +0.2 移速 +10%）。
- 弹球物理：瞄准方向 ±15° 扇形，速度 400 px/s，镜面反射；判定半径弹球 6 / 玩家 16。
