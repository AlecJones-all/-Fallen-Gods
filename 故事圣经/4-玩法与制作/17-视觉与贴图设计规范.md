# 17 · 视觉与贴图设计规范（对齐 BALL x PIT · v1.0）

> 本文件定义《帷外》**横屏打砖块战斗**的视觉约束：小怪、精英、Boss、弹球、场景、UI、贴图与占位方案。
> **依据**：横屏弹球战斗的功能可读性（带脸方块砖块墙、大型原创 Boss、发光反弹弹球、纵深场景）+ 03 人物/Boss + 04 舞台。**取代 11 号**旧"竖屏/立绘"视觉方案。
> **原创边界**：仅参考功能范式；具体角色、砖块表情、Boss 剪影、UI 边框/布局、图标、字体、色板、动画节奏、音效与场景摆布均为原创，详细禁用项以 18 号 0.1 为准。
> **原则**：一周无美术 → 用"功能可辨的占位"（带脸方块、几何拼装 Boss、发光球），不做纯色块；正式版按本文件出像素贴图。

## 〇、核心原则

1. **形似优先**：占位也要能看出"这是砖块怪 / 这是 Boss / 这是弹球"，不是纯色矩形。
2. **风格统一**：全部 2D 像素风，同一套调色板逻辑（每关一个主色调）。
3. **横屏构图**：16:9 宽幅，玩家底部、砖块墙/Boss 上方、两侧纵深装饰。
4. **辨识度**：小怪/精英/Boss 靠"剪影 + 尺寸 + 颜色"三档明显区分，一眼可辨。
5. **反馈必需**：受击闪白、反弹火花、死亡碎裂、伤害飘字。

## 一、A · 整体风格与分辨率

| 项 | 约束 |
|---|---|
| 画风 | 原创 2D 像素风，描边清晰、色块分明；采用希腊废墟 + 深坑封印的黑曜石/暗金/青蓝净礼光体系 |
| 横屏逻辑分辨率 | 640 × 360（16:9），×3 放大到 1920×1080 |
| 像素密度 | 贴图按 1× 像素绘制，整数倍放大（不模糊） |
| 调色板 | 每关一套主色调（见六、场景） |
| 背景层次 | 远（墙/天）/ 中（砖块墙+Boss）/ 近（玩家+弹球+前景装饰） |

## 二、B · 小怪（砖块）

| 项 | 约束 |
|---|---|
| 形态 | **带脸的方块砖块**（1 格），2 只眼睛必选（可加 1 张嘴/装饰） |
| 尺寸 | 1 格 = 32×32 px |
| 排布 | 砖块墙：每行 8–12 个、多行（按 15 号"每行密度"），整齐对齐 |
| 颜色 | 按关主题换色（每关 2–3 种小怪变体，靠颜色/表情区分） |
| 动画 | 待机（轻微上下浮动）/ 受击（闪白 + 抖动 0.1s）/ 死亡（碎裂成像素块飞散） |
| 占位 | 方块 + 两只白点眼睛 + 换色；受击闪白、死亡缩小消失 |

## 三、C · 精英怪

| 项 | 约束 |
|---|---|
| 形态 | **大型特殊方块**：2×1 或 2×2（占多格），带皇冠/角/獠牙等装饰 |
| 尺寸 | 64×32 或 64×64 px |
| 辨识 | **独特剪影 + 红光描边**，和普通砖块明显区分 |
| 颜色 | 比普通怪更饱和 + 发光边 |
| 动画 | 待机 / 受击闪白 / 蓄力发光（出特殊弹前）/ 死亡爆裂 |
| 占位 | 放大方块 + 描边发光 + 换色；出弹前闪红 |

## 四、D · Boss（大型原创生物）

> Boss 是关卡卖点，必须有"生物感"，不是放大色块。

| 关 | Boss | 造型要点 | 尺寸/占屏 |
|---|---|---|---|
| 5 | 刻菲索斯（河神） | 盘绕的蛇/龙形，多眼，鳞片金色+绿；坐在祭坛上 | 占屏宽 40–50% |
| 10 | 心魔（黑潮） | 无实体，涌动的黑潮/无面巨影 + 多只苍白眼睛 | 占屏宽 50% |
| 13 | 阿奈提俄斯（镜像） | 人形半神，戴"完美面具"，半身金色化，背后镜像重影 | 占屏宽 40% |
| 14 | 宙斯（雷霆巨像） | 威严巨像 + 雷霆 + 王冠，崩溃时裂开露出内部虚空 | 占屏宽 50–60% |
| 15 | 卡俄斯（深渊巨物） | 深坑裂口里的不可名状巨物（多眼/触须/虚空），只露局部 | 占满上部 |

- 共同：**右侧名称 + 血条**；**登场演出**（推镜/震屏/名称浮现）；受击闪白 + 抖动；死亡（碎裂/消散/被封印）。
- 占位：几何拼装（蛇=盘绕圆弧+眼、冰晶/虚空=多边形+眼），配色按 Boss 主题；至少"多眼+大体积"传达生物感。

## 五、E · 弹球 / 弹药

| 项 | 约束 |
|---|---|
| 形态 | 发光圆球 + 短轨迹 + 反弹火花 |
| 尺寸 | 16×16 px（判定半径 6 px，见 15 号 10.5） |
| 分色 | 8 弹珠 8 色：灼烧橙红 / 穿透银白 / 连锁电蓝 / 长矛铁灰 / 护盾金 / 吸血暗红 / 扭曲紫 / 分裂绿 |
| 反馈 | 撞砖块火花 + 伤害数字飘字；反弹次数的视觉提示（轨迹渐淡） |
| 占位 | 发光圆点 + 拖尾 + 撞墙小火花；按弹珠换色 |

## 六、F · 场景（横屏纵深）

| 项 | 约束 |
|---|---|
| 构成 | 地面 + 两侧墙/岩壁 + 3–5 个前景装饰（柱/刺/骨骼/机械） |
| 纵深 | 近大远小、前景遮挡、色调由近及远渐暗 |
| 每关主色调 | 见下表 |
| 占位 | 单色渐变底 + 几个几何装饰形状（柱子=竖条、冰刺=三角、骨骼=弧线） |

| 幕 | 关卡 | 主色调 | 装饰母题 |
|---|---|---|---|
| 一 | 1–5 | 暖黄/沙色 | 墓碑、神庙柱、河石 |
| 二 | 6–9 | 铁灰/暗紫 | 机械、锻炉、集市棚 |
| 三 | 11–14 | 岩褐/金白 | 深坑岩壁、判罪台、天门柱 |
| 终 | 10/15 | 暗金/近黑 | 封印纹路、深渊裂口、触须 |

## 七、G · UI（横屏）

| 位置 | 元素 |
|---|---|
| 左上 | 货币（Ichor / 律法残片 / 证据）图标 + 数值 |
| 左侧 | **弹珠槽 ×4 + 饰品槽 ×4**（图标 + 等级数字 1/2/3） |
| 顶部中 | 经验条（击杀升级） |
| 右侧 | Boss 血条 + 名称 / 关卡进度 |
| 右上 | 加速 / 跳过按钮 |
| 底部中 | 玩家角色（小英雄） |

- 风格：像素描边面板，和场景色调协调；占位用纯色底板 + 图标 + 数字。

## 八、H · 资产清单：占位 vs 正式贴图

| 资产 | 占位（一周） | 正式贴图数量 |
|---|---|---|
| 小怪（砖块） | 带脸方块 ×N 换色 | 5–8 种（每关 2–3 变体） |
| 精英 | 放大方块 + 描边 | 3–5 种 |
| Boss | 几何拼装 + 眼 | 5 个（刻菲索斯/心魔/阿奈提俄斯/宙斯/卡俄斯），各 2–3 帧 |
| 弹球 | 发光圆 + 拖尾 | 8 色 |
| 场景 | 单色渐变 + 装饰形状 | 8–10 张（按幕复用 + 换色） |
| UI | 纯色底板 + 图标 | 槽位/货币/血条/按钮一套 |
| 特效 | 通用粒子 | 罪痕光/帷裂/污秽黑烟/卡俄斯投影/震屏/火花 |

**动画帧最低要求**：小怪 待机/受击/死亡；精英 待机/受击/蓄力/死亡；Boss 待机/受击/攻击/死亡；弹球 飞行/反弹/命中。

## 九、与 11 号的关系

- 11 号是旧"竖屏战斗 + 横屏立绘剧情"方案，**本文件（横屏打砖块）取代其战斗视觉部分**。
- 11 号"省工作量/复用"五手段原则保留；"8–10 张 BG + 8–10 套立绘"清单按本文件第八节替换。
