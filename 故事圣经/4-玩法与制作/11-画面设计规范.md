# 11 · 画面设计规范（分镜脚本 · v1.0）

> 本文件定义剧情的逐画面分镜规范，是 10（展示方案）的细化、09（剧情脚本）的制作接口。
> **核心硬约束：画面精简，最小化绘图工作量。** 优先复用背景/立绘，靠差分与演出手段"换画面"，能不新画就不新画。
> 每个画面须标注【资产复用】，控制新绘预算。

## 〇、核心原则：省工作量优先

1. **复用优先**：同场景多画面共用一张背景；同角色共用一套立绘，只换表情差分。
2. **零绘图手段优先**：画面变化优先用——文本/旁白、运镜（推拉摇移）、表情差分、色调滤镜、通用特效、立绘位置移动、留白停顿。这些都不需要新画。
3. **新绘预算控制**：专属 CG 大图只在关键卖点处画（每高光≤1张）；其余用立绘+BG+运镜演出。
4. **背景只做差分**：同背景换昼夜/色调/局部元素表示时间或情绪变化，不重画整图。
5. **像素怪复用**：固定大小基础怪 + 换色/换部件变体；Boss/精英放大复用，不单独设计复杂结构。

## 一、一个"画面"的字段

| 字段 | 内容 |
|---|---|
| 画面ID | F01/F02… |
| 屏幕方向 | 横屏（剧情）/ 竖屏（战斗碎片） |
| 背景 BG | 场景图（**标注复用哪张**） |
| 立绘 | 角色 + 位置（左/中/右）+ **表情差分**（复用基础立绘） |
| 文本 | 说话人 + 台词（横屏≤60字）/ 旁白 |
| 特效 VFX | **通用特效**（罪痕光/帷裂/黑烟/震屏…复用） |
| 运镜 | 推近/拉远/摇移/震屏/淡入淡出/留白停顿（同一图即可实现） |
| 音频 | BGM + 音效SE |
| 交互 | 点击推进 / 选择肢 / 自动 |
| **资产复用** | **复用 / 差分 / 新绘**（新绘须注明理由） |

## 二、省工作量五手段

| 手段 | 做法 | 绘图成本 |
|---|---|---|
| **背景复用+色调差分** | 同BG换昼夜/冷暖色调/局部元素 | 0新绘（调色） |
| **立绘复用+表情差分** | 一套立绘+喜/怒/哀/疯狂等差分 | 差分小改，不重画 |
| **运镜代替新画** | 推拉摇移/震屏/特写，用同一张图 | 0新绘 |
| **通用特效复用** | 罪痕光/帷裂/Ichor金光/污秽黑烟/卡俄斯投影，做成通用粒子/光效 | 一次性，全程复用 |
| **文本/留白/停顿** | 靠台词、旁白、停顿2s叙事 | 0新绘 |

## 三、最小资产清单（控制总量）

**背景 BG（约8–10张关键图，同场景复用）**：
- 乱葬岗·夜（第1关）
- 忒弥斯庭（闪回通用）
- 涅斐勒城邦/义庄/河底（2–5关，共用城邦BG换局部）
- 铁城/兵器工坊（6–7关）
- 阿斯福德尔鬼市（8–9关）
- 帷内·封印内壁（10关）
- 泰坦之脊/判罪台（11–12关）
- 奥林匹斯·南天门/议事殿（13–14关）
- 帷裂·卡俄斯（15关）

**立绘（约8–10套，各带表情差分）**：
- 阿拉斯托尔（痛苦/冷静/愤怒/决意/疯狂）
- 忒弥斯（庄重/沉默/悲伤）
- 阿奈提俄斯（完美面具/空洞/崩溃/半神化）
- 宙斯（威严/崩溃）
- 帕那刻亚 / 斯忒尼俄斯 / 谟涅蒙 / 勒忒（各一套+少量差分）
- 律官/城隍等NPC（通用立绘换色复用）

**通用特效（一次性制作，全程复用）**：
- 罪痕发光 / 帷裂·帷合转场 / Ichor金光 / 污秽黑烟 / 卡俄斯投影 / 震屏 / 色调滤镜

**新绘预算**：
- 每高光专属CG≤1张（如卡俄斯投影、母亲补帷），仅关键卖点。
- 战斗像素怪：基础怪+换色/换部件变体，Boss放大复用。

## 四、剧情→画面拆解规则 + 数量估算

- 一个情绪beat/一句台词/一个动作 = 1画面（紧密可合并）。
- 换场景=换BG（优先复用已有BG）；情绪转折=表情差分/运镜；恐怖刺=单独1画面（留白+停顿）。
- **战斗过渡三拍**（见10第七补节）：入战拍/回战拍各1转场画面，复用帷合/帷裂通用特效，0新绘；战斗不可硬切。
- 数量估算：
  - 战斗飘字：1画面/刺（≤20字，1.5s，0新绘）
  - 波次间节点：3–6画面
  - 关卡开场/结算：4–8画面
  - 高光演出：10–20画面（新绘CG≤1）

## 五、横屏剧情画面布局

```
┌────────────────────────────┐
│        背景 BG（复用）        │
│   [立绘左·差分]   [立绘右·差分] │
│                            │
│  ┌──────────────────────┐  │
│  │ 说话人名              │  │
│  │ 台词（≤60字）         │  │
│  └──────────────────────┘  │
└────────────────────────────┘
```
旁白=居中半透明无框；选择肢=中部并列按钮；高光=全屏运镜（同一图推拉）。

## 六、示例：第1关"冤案闪回"8画面（全复用，0新绘）

| 画面 | 背景 | 立绘 | 文本 | 运镜/特效 | 资产复用 |
|---|---|---|---|---|---|
| F01 | 黑屏 | 无 | 旁白"夜。爱琴海的风裹着咸腥。" | 淡入 | 复用（黑屏） |
| F02 | 乱葬岗·夜 | 阿拉斯托尔·痛苦 | 旁白"他是被疼醒的。" | 推近 | 复用BG+立绘差分 |
| F03 | 乱葬岗·夜 | 阿拉斯托尔·痛苦 | 独白"罪痕像烧红的铁又回了一次炉。" | 罪痕光特写 | 复用+通用特效 |
| F04 | 乱葬岗·夜 | 阿拉斯托尔·冷静 | 独白"神力没了。" | 掌心特写 | 复用+表情差分 |
| F05 | 忒弥斯庭 | 律官（通用换色） | 判词"渎职破封…剥神力，烙罪痕，贬落人间。" | 公文特写 | 复用BG+通用立绘 |
| F06 | 忒弥斯庭 | 忒弥斯·沉默 | 旁白"她没看他。指节发白。" | 推近指节 | 复用+表情差分 |
