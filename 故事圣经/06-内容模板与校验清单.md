# 06 · 内容模板与校验清单（希腊版 v2.0 · DeepSeek-Flash 的输入）

> 本文件定义日常/支线/批量内容的统一格式、文风规范、逻辑校验清单与术语表。
> DeepSeek-Flash 依据本模板批量产出，并按校验清单自查。**出现设定冲突即判不合格，回炉重写。**

## 一、批量内容范围

DeepSeek-Flash 负责（不涉及主线锚点与结局判定）：
- 日常随机事件（填充各关随机池）
- 支线小任务（同道专属支线、人间黑幕支线）
- 物品文案（Ichor 道具、律法残片、黑神食禁药、证据碎片）
- 混沌之孽图鉴（怪物描述、弱点、掉落）
- NPC 闲聊、环境描写、战斗喊话等碎片文本

**不负责**：主线锚点剧情（Qwen4-Max）、玩法构筑（Step-5-Preview）、设定变更（人工）。

## 二、文风规范

1. **基调**：爽感为主+恐怖暗线（见00）。日常内容以志怪斩妖的爽利笔调为主，恐怖只在结尾"留一根刺"。
2. **句式**：短句为主，画面感强。避免堆砌形容词与空泛抒情。
3. **恐怖手法**：认知失调——先给合理解释，再补一行"不对劲"。禁止直白血腥与突发惊吓式描写。
4. **官僚讽刺**：神庭/人间黑幕用公文腔、考功术语制造窒息感（如"神绩核定""依律当贬""阿贡庭批红""神谕所示"）。
5. **希腊味**：用对神话典故（弑父循环、塔耳塔洛斯、尼克斯之畏、Ichor、Miasma、Katharsis、泰坦之脊），服务克系内核，不做神话科普堆砌。
6. **禁止**：提前泄露中层/深层真相（见01三层真相窗口）；自创设定名词；现代网络用语出戏；混用中式神庭词汇（城隍/酆都/玉帝等已废弃）。
7. **视角**：第三人称限知（紧贴阿拉斯托尔），恐怖暗线可用不可靠叙述。

## 三、内容模板

### 3.1 日常随机事件
```
事件ID：EV-{关号}-{序号}
类型：日常 / 支线 / 遭遇 / 机缘
触发关：第X关 随机池
前置条件：{变量条件，无则填"无"}
权重：{出现概率权重}
---
【标题】（≤12字，有志怪味）
【场景】（2~3句，画面+一根刺）
【正文】（80~150字，爽利推进，结尾留恐怖钩子或爽点）
【玩法buff选择】（引用05第五节模板，2~4项，标注变量增减；剧情单线无剧情选择肢）
【掉落/后果】（Ichor/Miasma/证据/声望/羁绊 增减）
【暗线钩子】（可选，1句"不对劲"，不得揭底）
【延迟兑现】（可选，标注"→第X关"）
```

### 3.2 混沌之孽图鉴
```
图鉴ID：YN-{序号}
名称：（希腊志怪命名，如"倒面鱼""纸钱魈""恩普萨""拉弥亚""克尔"）
阶位：低阶 / 中阶 / 高阶 / 渊隙级
出没关：第X~Y关
---
【形貌】（违背常理的细节，2~3句，恐怖载体）
【成因】（原初之力如何扭曲此生灵，1~2句，呼应世界观）
【弱点】（玩法提示，对应 Ichor/某神术）
【掉落】（Ichor 量 / 律法残片 / 污秽风险）
【图鉴尾注】（1句细思恐极的冷知识，不得揭底深层真相）
【禁则】不得揭底深层真相
```

### 3.3 物品文案
```
物品ID：IT-{序号}
名称：
品类：Ichor 道具 / 律法残片 / 黑神食禁药 / 证据碎片 / 命运之烬造物
---
【描述】（1~2句，外观+来历）
【效果】（玩法数值，引用02变量符号）
【代价】（污秽/蚀痕/声望，无则"无"）
【尾注】（1句来历暗线，可选）
```

### 3.4 同道专属支线
```
支线ID：SQ-{帕那刻亚/斯忒尼俄斯/谟涅蒙}-{序号}
所属同道：
羁绊要求：{1/2/3级}
触发关：第X关
---
【主题】（必须呼应同道弧光：帕那刻亚救世道/斯忒尼俄斯掀制度/谟涅蒙改判决）
【正文】（150~250字，情感+志怪）
【关键抉择】（支持其信念→羁绊+；背离→羁绊-，标注）
【奖励】（神术/羁绊/证据）
【禁则】不得提前泄露中层深层真相
```

## 四、逻辑校验清单（DeepSeek-Flash 自查，逐条过）

**设定一致性**
- [ ] 所有名词均在第七节术语表内，无自创设定，无废弃中式词汇。
- [ ] 力量描述符合02（Ichor/Miasma 双资源、七境、污秽阈值），无矛盾。
- [ ] 角色言行符合03动机/性格/秘密，无角色崩坏。
- [ ] 真相泄露检查：日常/支线未提前泄露中层（6–10关窗口）、深层（11–15关窗口）真相。

**结构一致性**
- [ ] 事件标注了触发关、前置、变量增减，格式符合模板。
- [ ] 选择肢有明确代价收益，无无脑最优解。
- [ ] 延迟兑现标注了目标关，且目标关在04中存在对应回收。
- [ ] 未改变04任何锚点事件的结局事实。

**克系修正一致性（v2.1）**
- [ ] 境界突破文本写"失去的人性"，不写单纯战力飙升。
- [ ] E1相关内容不写成暖结局，代价不可逆。

**文风一致性**
- [ ] 爽感为主，恐怖只在结尾留刺，比例约7:3。
- [ ] 无现代网络用语、无直白血腥、无突发惊吓。
- [ ] 短句、画面感、官僚讽刺、希腊味到位。

**数值合理性**
- [ ] 污秽增减在02锚点范围内（单事件建议+3~+15）。
- [ ] 掉落 Ichor/命运之烬量级与关卡进度匹配，不破坏经济。

> 自查输出：每条内容附"校验通过/不通过+原因"。不通过项回炉，不得带病提交。

## 六、协作与回炉流程

1. DeepSeek-Flash 按模板批量产出 → 自查清单 → 提交。
2. 校验方（可由人工或另一模型）抽检，冲突项记录到 `07-设定问题台账.md`。
3. 设定漏洞 → 人工裁决 → 统一修订00–04 → 更新版本号 → 相关批量内容回炉。
4. **严禁** DeepSeek-Flash 自行修改00–04设定来"消除冲突"。
