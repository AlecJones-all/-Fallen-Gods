> **核心定位**：竖屏弹球割草肉鸽。爽感为主+恐怖暗线；战斗给爽，恐怖放在"污秽账单"里。

## 〇、一句话玩法

竖屏矩形战场里，人物**自动发射可反弹的弹球 / 自动近战**，弹球在像素怪与墙之间反弹割草；玩家**走位躲敌弹 + 局内 buff 三选一构筑 + 局外永久养成**，一路推进 15 关掀翻腐败奥林匹斯。**无转生重置**，死亡=重试当前关。

## 一、战斗模型：竖屏弹球割草肉鸽

### 1.1 战场与核心循环

```
┌──────────────┐  ← 电脑上的竖屏矩形战场
│ 怪 怪 怪 怪 怪 │  ← 固定大小像素怪，阵列排布
│ 怪 [精英] 怪 怪│  ← 精英/Boss 体型更大、占多格
│ 怪 怪 怪 怪 怪 │
│      ●↗       │  ← 弹球碰墙/怪反弹造伤
│    ↙●         │
│  ╱ 近战自动挥击 │  ← 近战武器环绕人物自动攻击
│ 🧍 人物(反弹面) │  ← 弹球碰人物自动反弹
└──────────────┘
```

- **实时 + 自动攻击**：人物持续自动发射弹球 / 自动近战，玩家不用手动瞄准发射。
- **弹球反弹物理**：弹球碰墙/怪/人物反弹，有**反弹次数**上限，次数耗尽才消失。
- **无漏接惩罚**：弹球碰墙只要还有反弹次数就继续弹，纯爽无压力。
- **压力来源=走位躲敌弹**：像素怪会移动/吐弹，玩家走位躲；扣血来自被怪/敌弹碰到，不是漏接。

核心循环：
```
人物自动发射弹球 → 弹球碰墙/怪反弹造伤（反弹次数耗尽消失）
       ↑                              ↓
  玩家走位：躲敌弹 + 调整反弹角度 ← 弹球碰人物自动反弹
清光像素怪 → 波次结算 → 局内buff三选一 → 下一波
```

### 1.2 三种反弹机制

| 反弹 | 触发 | 作用 | 构筑维度 |
|---|---|---|---|
| **弹球反弹** | 自动发射的弹球碰墙/怪反弹 | 远程持续伤害 | 反弹次数/弹球数量/穿透/分裂 |
| **近战反弹** | 近战自动环绕挥击，带反弹属性 | 弹开敌弹/弹飞弹球+近战伤害 | 近战范围/反弹伤害/击退 |
| **人物反弹** | 弹球碰人物自动反弹（无惩罚） | 续航/充能/控落点 | 反弹面范围/碰球充能 |

### 1.3 玩家操作 = 走位 + 构筑

- **走位**：躲敌方弹幕、调整站位间接控制弹球反弹路径。
- **构筑**：局内 buff 三选一 + 局外养成。
- **爽感**：满屏自动反弹弹球割草，无漏接压力。

## 二、卡牌体系（局内构筑选择）

> 卡牌=局内构筑选择：波次间三选一 / 鬼市商店购买 / 事件掉落。
> 稀有度：凡品(白)→灵品(蓝)→神品(紫)→神器(金，律法残片合成)→**禁器(红，混沌专属)**。
> 资源模型：武器自动攻击无费用，区别在**污秽成本**；技能走**冷却**；Ichor 是商店货币+净礼资源；Miasma 是污秽仪表。

## 四、污秽引擎（叙事+战斗双影响，轻量代价）

**污秽值 0–100**，局内末日时钟。涨：混沌武器/禁术、吞噬怪物、被混沌敌击中、每关自然+5~10。

| 污秽 | 战斗·爽（收益） | 战斗·代价（轻量） | 叙事 |
|---|---|---|---|
| 0–30 清明 | 秩序神术稳定 | 混沌禁术锁定/弱 | 正常 |
| 30–60 低语 | 解锁禁术槽，混沌伤害+ | 屏幕边缘扭曲、偶现幻象 | 影子慢半拍 |
| 60–90 裂隙 | 禁术大幅增强 | 净礼回复轻微↓、幻象增多 | 看见帷的裂缝 |
| 90–100 溶解 | 禁术极强 | 净礼回复↓、秩序神术受限 | 自我溶解（恐怖氛围，结局固定E1） |

**平衡哲学**：混沌=爽快的另一种伤害+污秽账单，**不在战斗里狠罚**（无自伤/失控硬惩罚）。恐怖通过"越强越接近疯狂"的长期氛围体现（结局固定E1）。软张力：**混沌爆发 vs 秩序续航**（高污秽净礼回复略↓）。

**回落**：净礼坛 / 帕那刻亚 / 净礼道具可降污秽，但每次回落留**蚀痕**（永久，强化恐怖氛围，不决定结局）。回落不是免费后悔药。

## 七、事件节点玩法

- **净礼坛**：降污秽（留蚀痕）、治疗、净礼系 buff 选择。
- **鬼市（阿斯福德尔集市）**：卡牌/武器商店、情报（证据线索）、赃物交易、谟涅蒙/勒忒事件。
- **剧情锚点节点**：按 04 每关锚点触发（收同道/得证据/翻案/Boss），线性固定（单线单结局E1）。
- **波次间三选一**：局内 buff/卡/属性点构筑选择。

## 八、平衡哲学与克系落点

1. **战斗双族都爽**：秩序稳、混沌爆发，轻量代价，不劝退。
2. **恐怖在氛围**：污秽阈值叙事事件 + 恐怖氛围（结局固定E1），不在战斗狠罚。
3. **境界去威力化**：变强=失去人性（永久叙事代价）。
4. **宇宙冷漠**：卡俄斯只是消化，从未把主角当对手。
