## 一、判定口径

| 标记 | 含义 | 处理建议 |
|---|---|---|
| ✅ | 项目内已有独立模型（`art/` 或 `assets/environment/`），导入即可摆 | 不要再生成；只补绑定与动作 |
| 🟢 | 第三方包内已有同功能源件（`assets/anim_src/`），导入、调比例与材质即可 | 先试摆，不满意再生成 |
| 🟡 | 灰盒或关卡脚本用基础网格拼成的临时模型；可先摆用，但不是独立资产模型 | 先保留已经验证的场景与碰撞，之后再按需要换成独立模型 |
| 🟠 | 已有独立 GLB 源件（百万面级、未定标，尚未减面） | 未经改造也可直接接入，减面仅作性能优化 |
| 🔵 | 只有设定板或概念图，没有几何体 | 必须生成 |
| ❌ | 全库无相近资产 | 必须生成 |
| ➖ | 暂无模型，但已确认可先不做（可选补件，不阻塞通关） | 想补时再按提示词做 |
