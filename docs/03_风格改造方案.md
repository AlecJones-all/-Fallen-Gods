# 03 税卡场景制作方案（单场景 · 含复用规则）

> **范围锁死**：只做 `scenes/levels/tithe_gate_graybox.tscn` 这一个场景。
> 不为其他场景建任何文件、不做地区变体、不预热"以后可能用到"的东西。
> 复用只体现为三条规则 + 一张去向表，**现在不建**。

---

## 1 这个场景要做什么（玩法 + 叙事）

| 项 | 内容 |
|---|---|
| 剧情定位 | 节点 02「什一税道」，烬裔线开场，约 90 秒 |
| 空间 | 村口道 12m → 卡口 12m → 收储院 24m，总长 48m，路宽 8m |
| 流程 | 进场 → 走 5m 看见门梁 → 越过卡口触发 1v3 → 过秤 / 翻账册 / 看空笼 → 院子 3 敌 → 出口 |
| 教学 | 开局 5m 是安全区：走、冲刺、攻击各练一次，不用文字 |
| 叙事方式 | **零文本**。三件道具说事：空笼（人刚被拉走）、账册（名字被写成税基）、担架（盖着布） |
| 战斗 | 卡口 1v3（2 兵 + 1 射手）；院子 3 敌（2 兵 + 1 射手） |
| 交互 | 3 处：账本（门梁下）、秤（卡口前）、空笼（院子口） |

## 3 贴图怎么做（本场景 7 张）

- **烘焙一次，存 PNG**：256×256，lossless，`assets/materials/`
- 每张两张图：albedo + normal（法线从同一份高度场算，凹凸和花纹对得上）
- 材质用**世界三平面映射**，方块不用展 UV，改尺寸不拉伸
- 烘焙工具跑完自动执行 `godot --headless --import`

花纹规则（每种只说一件事）：

| 表面 | 花纹 |
|---|---|
| 白灰 | 细噪声 + 竖向裂缝（脊状噪声）+ 裂缝里充干血 |
| 龟裂石 | voronoi 式裂块 + 缝里压黑 + 表面细砂 |
| 骨 | 低频斑 + 细孔（高频点）+ 边缘亮 |
| 干木 | 竖向纤维 + 横向裂纹 + 上缘烟熏渐变 |
| 锈铁 | 铜绿斑（噪声阈值）+ 划痕 + 金属高光 |
| 腐布 | 经纬线 + 破损边缘 + 污渍斑 |
| 干血 | 不规则池状 + 边缘发黑 + 中心亮 |

## 5 复用规则（三条，现在只写规则不建东西）

### 规则一：尺寸
- 结构件必须 **2m 网格**（2×3×0.4 这种），原地拼接
- 道具自由尺寸，但**原点必须在底部中心**，+x 为正面

### 规则二：命名按"东西"命名，不按"地方"命名
- ✅ `wall_plaster`、`iron_rust`、`cage_hanging`
- ❌ `toll_wall`、`taxgate_cage`
- 原因：换个场景不用改名，直接复用

### 规则三：材质靠参数区分，不靠新建
- 同一个 `plaster` 用到礼拜堂时，只改 tint（蜡黄）和污渍强度，**不新建材质**
- 参数写在场景 JSON 里，不进代码

### 复用去向（记录用，本期不建任何文件）

| 模块 | 以后最可能出现在 |
|---|---|
| `wall_plaster` / `floor_tile` / `lantern_candle` / `blood_decal` | 所有场景 |

**批 3 踩到的四个坑**

1. **等距机位下"朝路"的面正好侧对相机**：模块正面是本地 +z，而世界转了 135°，本地 +z 恰好等于相机的右向量。所以账册板贴着"朝路"摆时被看成一条线。凡是需要读出面状的竖板/十字，必须转向来路（本地 yaw −90°）。
2. **贴地贴花被路面盖住**：路面块顶面在 y=0.045，贴花原本在 0.02–0.04，完全埋在里面。贴花件必须抬到 0.06 以上。
3. **铁链穿进拱石**：链在 z=±1.55 时正好穿过拱券起拱点（y≈1.6）。挪到 ±1.05、缩短到 2.45m 才落在拱洞空档里。

**关键几何结论（推翻原计划的一部分）**

正交相机可见地面 = `ortho / sin(pitch)` 深 × `ortho × 宽高比` 宽：
- ortho 12 / pitch −40 → **18.7 m 深 × 23.4 m 宽**
- 关卡宽 14 m，所以"界外"最多只有**两侧各 4.5 m**、前后约 7 m

因此 **2D 画板（天空/远山/大教堂）在这套相机下永远进不了画面**——地面会一直铺到画面顶端，没有地平线。已实测 ortho 9 / 12 / 16 / 20 四档，画板均不可见，代码与 1–2 s 的启动开销一并删除。

结论：这个游戏的"纵深"只能靠**物体**（断柱、碎石、枯树、雾），不能靠背景板。
