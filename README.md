希腊神话 × 克苏鲁 × 横屏打砖块割草肉鸽（玩法对齐 BALL x PIT · 球比伦战记）。律法女神忒弥斯之子阿拉斯托尔被冤下凡，从0修炼、聚同道、掀翻腐败的奥林匹斯神庭，最终直面"消化秩序"的原初之神卡俄斯。

- **基调**：爽感为主（约 70%）+ 恐怖暗线（约 30%），克系风味
